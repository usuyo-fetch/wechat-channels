**微信视频号**

usuyo 的获取插件：把你在视频号上看到、想留下的一条，用分享链接存到自己电脑上，用于个人备份、离线阅读和注意力整理。

- 平台：微信视频号（`wechat-channels`）
- 获取层级：`session-api`（只有借元宝那一步；不登录时是 `public-web`）；登录：`optional`；会用到：腾讯元宝账号（`yuanbao.tencent.com`）。不登录也能用。
- 上游：[ParseHub](https://github.com/z-mio/ParseHub)（MIT），移植了 `src/parsehub/provider_api/wxchannels.py` 的请求和解析，许可证原文在 `src/yuanbao.rs` 顶部。
- 用途：个人备份、离线阅读、注意力整理。只取你自己有权查看的内容，不发帖、不点赞、不私信。
- 账号与责任：平台可能限制或封禁账号。用不用、用哪个账号由你决定，后果由你自己承担。已知情况见 [调研 06 第 16 节](https://github.com/usuyo/usuyo/blob/main/docs/research/06-platform-access-and-account-risk.md#16-账号风险的证据)。
- 平台写操作：没有。
- 不托管任何平台内容。请遵守平台协议，尊重作者和版权人。权利人通知：{contact}。

## 它做什么

收到一条视频号分享链接（`https://weixin.qq.com/sph/…`，或在浏览器里打开后的 `channels.weixin.qq.com/finder-preview/pages/sph?id=…`）后：

两种方法（usuyo 协议 §2.3.1），各是一份快照：

1. **`feed-info`，不用任何账号**：调分享页自己会调的那个接口，存下作者、描述、封面和发布时间。快照里有 `meta.json`（短码、分享链接、作者、描述）、`feed.json`（接口的原样回答）和 `images/cover.jpg`。视频它取不到，总说缺视频。
2. **`yuanbao`，你登录了腾讯元宝时**：usuyo 见第一份缺视频，只要视频调它：用你的元宝登录换一个临时凭证，拿到视频地址，下载 MP4 存成 `media/video.mp4`。元宝的登录只交给这一种方法。

没登录元宝时，这条记成「部分」，缺的是视频，原因写「分享页没有给出视频地址」。以后登录了元宝，再取一次就补上视频。

清单里另外列了还没做的：网页版的浏览器脚本（`userscript`）、iPhone 镜像（`iphone`）、电脑微信（`mac`）、安卓手机（`android`）、录下口播（`audio`）。

## 它做不到的

- **不能自动列出你的「赞和收藏」**。视频号没有官方导出；能列清单的只有改写微信客户端的工具，每次微信更新都要跟着修。所以这里只收你一条条交过来的链接。
- 不取评论。
- 图片帖、直播没有视频文件，只存作者、描述和封面。
- 视频地址给出的不是能直接播放的 MP4 时，`yuanbao` 回失败并写明原因，不存那个文件。

## 链接怎么从手机到电脑

1. 在手机的视频号里点「分享」，选「复制链接」。
2. 把链接放进 usuyo 的收件文件夹：例如用快捷指令把剪贴板写成一个 `.txt`，存进 iCloud 云盘里你在 usuyo 设置里选的那个文件夹。一个 `.txt` 里可以有多个链接，也可以是整段分享文字。
3. 电脑上的 usuyo 看到这个文件，就交给本插件去取。

也可以把链接直接粘贴进电脑上的 usuyo。

手机上的分享菜单里有没有「复制链接」、复制出来的是不是 `weixin.qq.com/sph/` 链接，要在你的手机上看一次；这条路靠它。

## 元宝那一步对你的元宝账号意味着什么

- usuyo 先让你在它的登录窗口里登录腾讯元宝，登录态存在本机。只有要取视频时，宿主才把元宝的 cookie 交给本插件。
- 本插件拿你的元宝 cookie，向 `yuanbao.tencent.com` 发一次请求，请元宝解析这条分享链接；元宝回一个临时凭证，插件再用这个凭证（不带 cookie）向视频号的分享页接口要视频地址。
- 在元宝看来，就是你的账号让它解析了一条视频号链接。元宝账号有被封的先例：有人把这条路做成公开服务，被大量调用。usuyo 默认每两条之间至少隔 30 秒；批量交来的每天最多 50 条（你手动一条条收下的不计这个数）。这些都可以在设置里改得更慢。
- cookie 只发给 `yuanbao.tencent.com`，不跟随跳转，不写进日志、快照或缓存；元宝的回答和临时凭证也不存。
- 元宝的登录过期时，本插件报「要重新登录腾讯元宝」，不会用旧的登录反复去试。
- 不想用元宝账号，就不登录元宝；作者、描述和封面照样能存。
